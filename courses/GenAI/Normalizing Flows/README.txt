TRANSFORMERS & NORMALIZING FLOWS STUDY STUDIO — OFFLINE EDITION

OPEN THE STUDIO

1. Keep this entire folder together.
2. Open index.html in a modern browser. No network connection is needed.
3. Notes, progress, Nabla quiz attempts, and chapter summaries are saved by
   that browser on this device.
4. Use Export JSON regularly to create a portable version-1 backup.
5. Use Import JSON to restore that backup. The studio asks before replacing
   any existing notebook state.

REASSEMBLE THE DOWNLOADABLE ARCHIVE

The downloads folder contains two numbered parts. Put both parts in the same
folder, join them in number order, and then unzip the result.

macOS or Linux:
  cat transformers-normalizing-flows-study-studio-offline.zip.part-01 \
      transformers-normalizing-flows-study-studio-offline.zip.part-02 \
      > transformers-normalizing-flows-study-studio-offline.zip

Windows Command Prompt:
  copy /b transformers-normalizing-flows-study-studio-offline.zip.part-01+
          transformers-normalizing-flows-study-studio-offline.zip.part-02
          transformers-normalizing-flows-study-studio-offline.zip

The archive deliberately excludes its own downloads folder so packaging never
recurses. After extraction, open Normalizing Flows/index.html.
